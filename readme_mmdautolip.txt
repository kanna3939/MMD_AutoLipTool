============================================================
MMD_AutoLipTool 簡易説明書
============================================================

このファイルは、MMD_AutoLipTool の配布版を使う方向けの簡単な説明書です。

MMD_AutoLipTool は、テキストファイルと音声ファイルから、
MikuMikuDance（MMD）用の口パク VMD ファイルを作成する補助ツールです。

生成されるリップモーションは自動生成です。
最終的な見た目は、MMD 側でモデルに読み込んで確認し、
必要に応じて調整してください。


------------------------------------------------------------
1. このツールでできること
------------------------------------------------------------

MMD_AutoLipTool では、以下のような作業ができます。

・テキストファイルを読み込む
・音声ファイルを読み込む
・音声に合わせたリップモーションを自動生成する
・MMD で読み込める VMD ファイルを書き出す

使用する口パク morph は、基本的に以下の 5 種類です。

・あ
・い
・う
・え
・お

このツールは、MMD のリップモーション作成を補助するためのものです。
人間が手作業で作ったような完全な表情付けや、細かい口の演技を自動で作るものではありません。


------------------------------------------------------------
2. 動作環境
------------------------------------------------------------

対象OS:

・Windows 11

このツールは Windows 向けのデスクトップアプリです。
Webブラウザ上で使うツールではありません。

配布版を使う場合、通常は Python のインストールや GitHub の操作は不要です。


------------------------------------------------------------
3. ZIPを展開してください
------------------------------------------------------------

配布 ZIP をダウンロードしたら、まず ZIP を展開してください。

重要:
ZIP の中から直接 exe を起動しないでください。

おすすめ手順:

1. ZIP ファイルを右クリックします
2. 「すべて展開」を選びます
3. 分かりやすい場所に展開します
   例: デスクトップ、ドキュメント、作業用フォルダなど
4. 展開したフォルダの中にある exe を起動します

例:

MMD_AutoLipTool.exe

フォルダ内のファイル構成を勝手に変更すると、正常に動かない場合があります。
exe だけを別の場所へ移動せず、展開したフォルダごと使ってください。


------------------------------------------------------------
4. 基本的な使い方
------------------------------------------------------------

基本的な流れは以下です。

1. MMD_AutoLipTool.exe を起動します

2. テキストファイルを選びます

   読ませたいセリフや歌詞を書いたテキストファイルを選んでください。
   テキストファイルは UTF-8 形式を推奨します。

3. 音声ファイルを選びます

   対応している音声ファイルを選んでください。
   現在の配布版では、基本的に WAV ファイルを使用してください。

4. 出力先を指定します

   生成する VMD ファイルの保存先を指定します。

5. 生成を実行します

   ツールがテキストと音声をもとに、口パク用の VMD ファイルを作成します。

6. MMD で確認します

   生成された VMD ファイルを MMD でモデルに読み込み、
   口パクの見た目を確認してください。


------------------------------------------------------------
5. 入力ファイルについて
------------------------------------------------------------

■ テキストファイル

・UTF-8 形式のテキストファイルを推奨します
・日本語のセリフや歌詞を入力できます
・極端に長い文章では、処理に時間がかかる場合があります

メモ帳で保存する場合は、文字コードが UTF-8 になっているか確認してください。

■ 音声ファイル

・WAV ファイルを使用してください
・MMD で使う音声と同じ内容のファイルを使うと確認しやすくなります

注意:
MP3 などの形式に対応していない配布版では、事前に WAV に変換してから使用してください。


------------------------------------------------------------
6. 出力ファイルについて
------------------------------------------------------------

このツールは、MMD で読み込める VMD ファイルを出力します。

出力例:

・lip_motion.vmd
・serif_lip.vmd
・song_lip.vmd

生成した VMD ファイルは、MMD 側でモデルに読み込んで確認してください。

モデルによっては、口パク morph の名前や動き方が異なる場合があります。
このツールは、基本的に以下の morph 名を使うモデルを想定しています。

・あ
・い
・う
・え
・お


------------------------------------------------------------
7. MMDでの確認について
------------------------------------------------------------

生成した VMD は、MMD でモデルに読み込んで確認してください。

確認すること:

・口が動いているか
・音声と大きくずれていないか
・口の開き方が強すぎないか
・不自然な動きがないか
・モデルの morph 名が合っているか

自動生成のため、完全に自然な口パクになるとは限りません。
必要に応じて、MMD 側でフレームや morph を調整してください。


------------------------------------------------------------
8. うまく動かないとき
------------------------------------------------------------

■ exe が起動しない

・ZIP を展開してから起動しているか確認してください
・exe だけを別の場所へ移動していないか確認してください
・Windows Defender やセキュリティソフトの警告が出ていないか確認してください

■ テキストが文字化けする

・テキストファイルが UTF-8 形式か確認してください
・別の文字コードで保存されたファイルは、正しく読めない場合があります

■ 音声ファイルが読み込めない

・対応している形式か確認してください
・現在の配布版では、基本的に WAV ファイルを使用してください
・ファイル名やフォルダ名に特殊な文字が含まれている場合は、簡単な名前に変えて試してください

■ VMD が出力されない

・出力先フォルダに書き込み権限があるか確認してください
・ファイル名に使えない文字が入っていないか確認してください
・すでに同名ファイルを MMD などで開いていないか確認してください

■ MMDで口が動かない

・モデルに「あ / い / う / え / お」の morph があるか確認してください
・VMD を正しいモデルに読み込んでいるか確認してください
・出力された VMD ファイルが空でないか確認してください


------------------------------------------------------------
9. Windows Defender などの警告について
------------------------------------------------------------

このツールは個人開発の Windows アプリです。

配布版の exe は、環境によって Windows Defender やセキュリティソフトに
警告される場合があります。

警告が出た場合は、以下を確認してください。

・公式の配布元からダウンロードしたものか
・ZIP の中身が説明と合っているか
・不審な場所から入手したファイルではないか

この説明は、すべての警告が誤検知であることを保証するものではありません。
不安な場合は、使用を中止してください。

------------------------------------------------------------
11. 既知の制限
------------------------------------------------------------

・生成される口パクは自動生成の補助モーションです
・最終的な見た目は MMD 側で確認してください
・morph 名は基本的に「あ / い / う / え / お」を想定しています
・モデルによっては、口の動き方が想定と異なる場合があります
・長い音声や長いテキストでは、処理に時間がかかる場合があります
・音声とテキストの内容が大きく違う場合、口パクが合いにくくなります
・未署名の exe のため、環境によっては警告が出る場合があります

13. 最後に
------------------------------------------------------------

MMD_AutoLipTool は、MMD での口パク作成を少し楽にするための補助ツールです。

モデルや音声によっては調整が必要です。

MMD 側で実際に再生しながら、必要に応じて修正して使ってください。
