============================================================
MMD_AutoLipTool 簡易説明書
============================================================

このファイルは、MMD_AutoLipTool の配布版を使う方向けの簡単な説明書です。

対象とする正式版数: 1.0.0

MMD_AutoLipTool は、音声ファイルと、必要に応じてテキストファイルから、
MikuMikuDance（MMD）用の口パク VMD ファイルを作成する補助ツールです。

生成されるリップモーションは自動生成です。
最終的な見た目は、MMD 側でモデルに読み込んで確認し、
必要に応じて調整してください。


------------------------------------------------------------
1. このツールでできること
------------------------------------------------------------

MMD_AutoLipTool では、以下のような作業ができます。

・テキストファイルを読み込む
・音声ファイルを読み込む
・テキストファイルを使わず、音声の書き起こしから口パクを作る
・音声から得た書き起こし結果を確認・編集する
・明示された長音（「ー」）を、口形の維持または終端で0へ減衰する表現にする
・音声に合わせたリップモーションを自動生成する
・MMD で読み込める VMD ファイルを書き出す
・必要に応じて、MMD 用 WAV ファイルを書き出す
・「ファイル > MMD一括出力...」から、VMD・MMD用WAV・診断レポートを専用フォルダへ一括出力する
・組み込み／ユーザープリセットで生成設定を再利用する
・モデルプロファイルで母音名セットや生成設定を再利用する
・Whisperモデル（small / medium / turbo）を選び、明示的に取得・検証して切り替える

プロファイルなしで使用する口パク morph は、以下の日本語 5 種類です。

・あ
・い
・う
・え
・お

「モデルプロファイル」タブでは、組み込みの日本語5母音または英字5母音
（A / I / U / E / O）を選択できます。プロファイルは `profiles.json` に保存され、
最大100件まで作成できます。適用中のプロファイルは値の変更・削除がロックされ、
名前変更だけが許可されます。

このツールは、MMD のリップモーション作成を補助するためのものです。
人間が手作業で作ったような完全な表情付けや、細かい口の演技を自動で作るものではありません。


------------------------------------------------------------
2. 動作環境
------------------------------------------------------------

対象OS:

・Windows 11

このツールは Windows 向けのデスクトップアプリです。
Webブラウザ上で使うツールではありません。

配布版を使う場合、通常は Python のインストールや GitHub の操作は不要です。


------------------------------------------------------------
3. ZIPを展開してください
------------------------------------------------------------

配布 ZIP をダウンロードしたら、まず ZIP を展開してください。

重要:
ZIP の中から直接 exe を起動しないでください。

おすすめ手順:

1. ZIP ファイルを右クリックします
2. 「すべて展開」を選びます
3. 分かりやすい場所に展開します
   例: デスクトップ、ドキュメント、作業用フォルダなど
4. 展開したフォルダの中にある exe を起動します

例:

MMD_AutoLipTool.exe

フォルダ内のファイル構成を勝手に変更すると、正常に動かない場合があります。
exe だけを別の場所へ移動せず、展開したフォルダごと使ってください。


------------------------------------------------------------
4. 基本的な使い方
------------------------------------------------------------

基本的な流れは以下です。

1. MMD_AutoLipTool.exe を起動します

2. テキストファイルを使うか選びます

   TEXTあり入力では、読ませたいセリフや歌詞を書いたテキストファイルを選びます。
   テキストファイルは UTF-8 形式を推奨します。
   音声のみ入力では、テキストファイルを選ばず次へ進みます。

3. 音声ファイルを選びます

   対応している音声ファイルを選んでください。
   現在の配布版では、WAV / MP3 / M4A を選択できます。

4. 解析を実行します

   「処理実行」を押します。
   音声のみ入力では、音声から書き起こし、ひらがな、母音列を生成します。

5. 音声のみ入力の書き起こしを確認します

   修正した場合は「適用」を押し、もう一度「処理実行」を押してください。
   再解析が終わるまでは VMD を保存できません。

6. 長音の表現を選びます

   右側の「プリセット」から「標準（長音維持）」または「長音減衰」を選び、
   「選択したプリセットを適用」を押します。選択だけでは反映されません。
   「長音減衰」は長音の終端で値が0になります。ユーザープリセットは
   `presets.json` に保存され、保存に失敗しても組み込みプリセットは利用できますが、
   同じ起動中のユーザープリセット変更は停止します。

7. 必要に応じてモデルプロファイルを選びます

   右側の「モデルプロファイル」からプロファイルを選び、
   「選択したモデルプロファイルを適用」を押します。プロファイルなしを適用すると、
   日本語5母音へ戻ります。作成・更新・削除も同じタブから行います。
   `profiles.json` の読み込みや保存に失敗した場合は、プロファイルなしで継続し、
   ユーザープロファイルの変更は停止します。

8. 必要に応じて母音イベントを個別に補正します

   Preview上の母音イベントをクリックし、右側の「選択イベント」で値を編集します。
   Ctrl+Z / Ctrl+Y、または「編集」メニューから補正を元に戻す・やり直す操作ができます。

9. 診断内容を確認します

   右側の「Info」と「Warning」で、入力・解析・生成・保存可否と
   INFO / WARNING / ERROR の診断内容を確認します。

10. VMD を保存します

   解析完了後に「VMD保存」から保存先を指定します。

11. 必要に応じて診断レポートを保存します

   メニューの「ファイル」から「診断レポート保存...」を選ぶと、
   元音声名に「_report.txt」を付けた診断レポートを保存できます。

12. VMD・MMD用WAV・診断レポートをまとめて出力する場合

   メニューの「ファイル」から「MMD一括出力...」を選びます。
   親フォルダとfolder名を指定でき、既定のfolder名は
   「<音声名>_MMD」です。専用folderへ次の3ファイルを出力します。

   ・<audio_stem>_lip.vmd
   ・<audio_stem>_mmd.wav
   ・<audio_stem>_report.txt

   一括出力は現在の編集状態から3成果物を再生成します。個別に保存済みの
   VMDやMMD用WAV、診断レポートは流用しません。同名の出力先がある場合は
   別のfolder名を指定してください。既存folderのmerge・置換は行わず、
   失敗やキャンセル時も既存の出力を保護します。

13. MMD で確認します

   生成された VMD ファイルを MMD でモデルに読み込み、
   口パクの見た目を確認してください。

14. 次の素材を扱う場合

   メニューの「ファイル」から「新規作業...」を選びます。
   確認後、現在の入力・書き起こし・解析結果を初期化して、次の音声や
   テキストを読み込めます。

補足:

必要な場合は、専用の「MMD用WAV出力」から MMD で読み込ませるための
WAV ファイルを書き出してください。

一括出力を使う場合は、専用folder内の`<audio_stem>_mmd.wav`をMMDで
読み込ませてください。個別のMMD用WAV出力も引き続き利用できます。

ERROR の診断がある場合は VMD を保存できません。WARNING の診断が
ある場合は、同じ解析・設定状態の初回保存時だけ確認画面が表示されます。
診断レポートは VMD 保存不可の状態でも、元音声が読み込まれていれば
保存できます。

解析中止を押した直後は処理終了まで操作の一部がロックされたままです。
変更前の有効な解析結果を再利用できる場合は、個別補正とUndo / Redo履歴も
復元します。

再解析に失敗しても変更前の結果を安全に再利用できる場合は、旧Previewと
個別補正を確認用に復元します。ただしERRORが表示され、VMDは保存できません。
その状態から再解析をキャンセルしても、既存ERRORと保存禁止は維持されます。

「新規作業...」では、元のテキスト・音声、保存済みVMD・MMD用WAV、
保存済み診断レポート、解析用WAVキャッシュは削除されません。最近使った
ファイル、テーマ、各種パラメータ、保存先の履歴は保持されます。
処理中は実行できません。


------------------------------------------------------------
4-1. Whisperモデルを切り替える場合
------------------------------------------------------------

音声のみ入力では、Whisperモデルを `small`、`medium`、`turbo` から選べます。
通常は `small` が初期選択されています。

安全に切り替える手順:

1. 右側の「Whisperモデル」タブで候補を選びます。
   候補を選ぶだけでは、ダウンロード、現在のモデル変更、解析は始まりません。

2. 「保存状態」が「未配置（Download & Verifyが必要）」または
   「未完了（Download & Verifyが必要）」の場合は、「Download & Verify」を押します。
   明示確認後だけ、公式URLからforegroundで取得します。取得後はexact sizeと
   SHA256を検証し、検証に失敗したファイルは解析へ使用しません。

3. 「保存状態」が「確認済み」になったら、「選択モデルを適用」を押します。
   適用が成功すると現在のWhisperモデルが切り替わります。入力済みのTEXTや音声が
   ある場合は、新しいモデルで再解析が始まります。

4. 解析中にモデルを自動取得することはありません。モデルがない、壊れている、
   読み込めない場合は安全に失敗を表示します。音声が外部へ送信されることもありません。

モデルの保存先は、通常は実行ファイルに隣接する `models` フォルダです。
「保存先を変更」からローカルの保存先を選べます。モデルの重みは配布ZIPには
同梱せず、ユーザーが明示した操作で保存先へ取得します。


------------------------------------------------------------
5. 入力ファイルについて
------------------------------------------------------------

■ テキストファイル

・UTF-8 形式のテキストファイルを推奨します
・日本語のセリフや歌詞を入力できます
・極端に長い文章では、処理に時間がかかる場合があります

メモ帳で保存する場合は、文字コードが UTF-8 になっているか確認してください。

■ 音声ファイル

・WAV / MP3 / M4A ファイルを使用できます
・MMD で使う音声と同じ内容のファイルを使うと確認しやすくなります

注意:
音声解析と波形表示には、ツール内部で生成した解析用 WAV を使用します。
MMD で読み込ませる WAV が必要な場合は、「MMD用WAV出力」から保存してください。


------------------------------------------------------------
6. 出力ファイルについて
------------------------------------------------------------

このツールは、MMD で読み込める VMD ファイルを出力します。
また、専用の「MMD用WAV出力」から MMD 用 WAV ファイルを出力できます。
MMD 用 WAV は、個別にはVMD保存時に自動で同時出力されず、専用の
「MMD用WAV出力」から保存します。まとめて渡したい場合は、
「MMD一括出力...」から現在の状態を使って専用folderへ3成果物を再生成できます。

一括出力の既定folder名は「<audio_stem>_MMD」です。出力例:

・<audio_stem>_MMD/<audio_stem>_lip.vmd
・<audio_stem>_MMD/<audio_stem>_mmd.wav
・<audio_stem>_MMD/<audio_stem>_report.txt

同名の出力先がある場合は別のfolder名を指定してください。既存folderの
merge・置換は行わず、失敗やキャンセル時も既存の出力を保護します。

出力例:

・lip_motion.vmd
・serif_lip.vmd
・song_lip.vmd

生成した VMD ファイルは、MMD 側でモデルに読み込んで確認してください。

モデルによっては、口パク morph の名前や動き方が異なる場合があります。
プロファイルなしでは、以下の morph 名を使うモデルを想定しています。

・あ
・い
・う
・え
・お

英字モデルでは、英字プロファイルを適用して `A / I / U / E / O` を使用します。


------------------------------------------------------------
7. MMDでの確認について
------------------------------------------------------------

生成した VMD は、MMD でモデルに読み込んで確認してください。

確認すること:

・口が動いているか
・音声と大きくずれていないか
・口の開き方が強すぎないか
・不自然な動きがないか
・モデルの morph 名が合っているか

自動生成のため、完全に自然な口パクになるとは限りません。
必要に応じて、MMD 側でフレームや morph を調整してください。


------------------------------------------------------------
8. うまく動かないとき
------------------------------------------------------------

■ exe が起動しない

・ZIP を展開してから起動しているか確認してください
・exe だけを別の場所へ移動していないか確認してください
・Windows Defender やセキュリティソフトの警告が出ていないか確認してください

■ テキストが文字化けする

・テキストファイルが UTF-8 形式か確認してください
・別の文字コードで保存されたファイルは、正しく読めない場合があります

■ 音声ファイルが読み込めない

・対応している形式か確認してください
・WAV / MP3 / M4A のいずれかを使用してください
・ファイル名やフォルダ名に特殊な文字が含まれている場合は、簡単な名前に変えて試してください

■ VMD が出力されない

・解析が正常に完了しているか確認してください
・書き起こしを編集した場合は、適用後に再解析してください
・出力先フォルダに書き込み権限があるか確認してください
・ファイル名に使えない文字が入っていないか確認してください
・すでに同名ファイルを MMD などで開いていないか確認してください

■ MMDで口が動かない

・適用中のプロファイルに対応する morph（日本語なら「あ / い / う / え / お」、
  英字なら「A / I / U / E / O」）がモデルにあるか確認してください
・VMD を正しいモデルに読み込んでいるか確認してください
・出力された VMD ファイルが空でないか確認してください


------------------------------------------------------------
9. Windows Defender などの警告について
------------------------------------------------------------

このツールは個人開発の Windows アプリです。

配布版の exe は、環境によって Windows Defender やセキュリティソフトに
警告される場合があります。

警告が出た場合は、以下を確認してください。

・公式の配布元からダウンロードしたものか
・ZIP の中身が説明と合っているか
・不審な場所から入手したファイルではないか

この説明は、すべての警告が誤検知であることを保証するものではありません。
不安な場合は、使用を中止してください。

11. 既知の制限
------------------------------------------------------------

・生成される口パクは自動生成の補助モーションです
・最終的な見た目は MMD 側で確認してください
・morph 名は基本的に「あ / い / う / え / お」を想定しています
・モデルによっては、口の動き方が想定と異なる場合があります
・長い音声や長いテキストでは、処理に時間がかかる場合があります
・音声とテキストの内容が大きく違う場合、口パクが合いにくくなります
・未署名の exe のため、環境によっては警告が出る場合があります
・音声のみ入力の書き起こし精度やタイミングは、音質や発話状態により変わります
・書き起こしやタイミングを取得できない場合は、音声を確認して再解析してください
