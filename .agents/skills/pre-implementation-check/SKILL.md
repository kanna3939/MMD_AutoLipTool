# Pre-implementation check

適用される`AGENTS.md`の権限・初動・検証規則に従い、ユーザーが限定した対象や禁止操作を越えない。
以下はこのSkillを使う作業の手順であり、タスク全体に別の承認工程を追加しない。対象・前提が変わっていない取得済みの証拠は再利用する。

## Workflow

1. 対象計画と適用される`AGENTS.md`を確認し、Git状態、コード、テスト、パッケージ設定、文書を計画の照合に必要な範囲で確認する。
2. 計画の対象ファイル、関数、クラス、状態、データ契約が現在のリポジトリに実在するか確認する。
3. 各要求について、既存挙動、変更点、テスト可能性、互換性、例外、依存・配布影響を照合する。
4. 古い前提、実装済みとの重複、未定義の責務、検証不能な受け入れ条件を検出する。
5. 代替説明や例外条件を確認し、着手可、条件付き可、要修正のいずれかを明確に判定する。
6. 問題を重要度順に示し、計画修正で解決するものと実装時に扱うものを分ける。

## Boundaries

- レビュー対象のコード、テスト、計画、文書を修正しない。報告書の保存が明示依頼されている場合は、その成果物だけを作成・更新できる。
- 将来候補や過去計画を現在の仕様として扱わない。
- 対象リポジトリの実測を一般的なPython慣行より優先する。

## Output

判定、確認範囲、計画との整合、問題、着手前に必要な対応、未確認事項を報告する。
