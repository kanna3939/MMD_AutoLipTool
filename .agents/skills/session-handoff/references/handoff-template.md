# Session handoff template

```md
# 次セッション引き継ぎ

## 現在のリポジトリ状態
- ブランチ:
- 最新コミット:
- 作業ツリー:
- remote同期:

## 完了・検証状況
- 実装済み:
- 検証済み:
- 未検証・未完了:

## 次セッションの目的
- フェーズ:
- 作業範囲:
- 行わないこと:

## 最初に確認すること
- コマンド:
- ファイル:

## 注意事項
- 保護すべき変更:
- 既知の問題:
- 未確認事項:

## 完了時の報告形式
```

空欄を一般論で埋めず、確認できた現在状態だけを書く。プロジェクト固有の開始コマンドと報告形式が`AGENTS.md`にある場合はそちらを優先する。
